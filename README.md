# general-ppt（通用 PPT 生成器）

> 通用中文 PPT 制作技能，由一次高校说课 PPT 实战蒸馏而成。
> 核心价值：**问需求 → 补密度 → 口述确认 → 设计感选型 → 模板生成 → 真实图 → 清理统一 → 渲染交付**，产出可编辑 PPTX。

AI 做 PPT 最容易翻车的五件事，本技能全部提前拦截：

1. **信息密度不够** —— 每页都是"提升教学质量"式空话，撑不起讲台 1 分钟
2. **配图假** —— AI 编造软件界面、无意义装饰图，一眼假
3. **模板残留** —— 模板自带的思政/法治/会计示例文字留在成品里，事故级翻车
4. **模板老气/死搬硬套** —— 内置模板偏旧、整份 deck 同一版式套到底，没有设计感
5. **信息倾倒** —— 每页塞 300-500 字、表格挤满数据，观众 3 秒抓不到重点（v2.1 新增拦截）

---

## 五大支柱

| 支柱 | 做法 |
|---|---|
| **问需求** | 不动手前先问清 4 件事：目的受众 / 内容材料 / 图片偏好 / 风格颜色 |
| **信息密度** | 追问补数字案例 → 5 项自审（数字/案例/对比/无空话/能讲 1-2 分钟）→ 不过就打回追问 |
| **设计感** | 默认网搜新潮模板给用户看图选（gorden 内置只兜底）→ 三方向候选 → 封面/章节页用平台生图模型整页生成主视觉 → 版式多样性硬规则 + 反老气清单 |
| **真实图** | 网络真实图优先并标来源；界面图必须真实截图；AI 生图仅最后兜底 |
| **克制（设计纪律）** | 烂 PPT=信息倾倒，发布会级 PPT=认知引导。一页一个核心信息、其余留白（v2.1 新增） |

## 设计感三保障（v2 新增）

| 保障 | 做法 | 解决的问题 |
|---|---|---|
| **模板来源升级** | 未指定模板时默认先网搜新潮、贴合场景的模板，给用户 2-3 个候选**附预览图**确认后再生成；gorden-ppt-skill 内置 21 套只当兜底 | "模板特别古老、死搬硬套" |
| **三方向候选** | 风格/模板候选至少 2-3 个让用户**看图选**，不报一个名字让用户凭空想象 | 用户说不清"高级感"是什么 |
| **版式多样性** | 一份 deck ≥N 种版式（10 页下 ≥6、10 页上 ≥8）；禁止连续 3 页同一主体结构；选页优先挑视觉差异大的模板页 | 整份 deck 同一版式套到底 |

**反老气/反 AI 味清单**（选模板和生图时逐条过）：禁 2010 年代模板感（大红/大绿/深蓝渐变、发光按钮、剪贴画图标、厚重阴影）；禁紫渐变白底、满屏圆角卡片、Inter/Arial 通用字体堆砌；禁非序列却用 01/02/03 编号、全大写小标签；生图主视觉宁可克制留白不堆装饰。

## 设计纪律五铁律（v2.1 新增）

| 铁律 | 做法 |
|---|---|
| **颜色 ≤ 3 种** | 主色+辅色+点缀色各 1，附色号，严格执行 |
| **字体 ≤ 2 种** | 标题字体 + 正文字体各 1，层级清晰 |
| **每页文字 ≤ 50 字** | 一页一个核心信息，详细内容放演讲备注；页面核心提炼 ≤ 20 字 |
| **数据大字号呈现** | 大字号数字 + 一句结论，禁表格挤满 / 截图粘贴 |
| **逻辑 = 认知引导** | 每页回答一个问题，下一页给答案；留白是高级感来源 |

**认知引导叙事弧线**（按受众选结构，别按材料顺序排）：

- 给投资人：痛点 → 方案 → 数据验证 → 团队 → 愿景
- 给客户：场景 → 问题 → 解决方案 → 案例 → 服务
- 给老板汇报：结论 → 数据支撑 → 下一步计划
- 教学课件（默认）：是什么 → 为什么 → 怎么做 → 怎么评

**每页设计指令表**（生成每一页前先定，当作"装修施工图"）：页面类型 [全图 / 左图右字 / 数据大字号 / 纯文字] + 主标题 ≤10 字 / 副标题 ≤30 字 + 数据呈现 + 视觉方向。整套 deck 先出指令表再生成，保证全部页面在同一套视觉体系里。

## 9 步工作流

1. **开场 4 问**（目的受众 / 内容材料 / 图片偏好 / 风格颜色，数字作答）
2. **内容收集**（围绕论点挖数字、案例、细节、依据，禁止编造）
3. **信息密度自审**（5 项清单，不过 → 打回第 2 步；自审后做**内容减法**：提炼每页核心 ≤20 字、识别数据、找重复/冗余/矛盾页，输出"原页码/核心信息/关键数据/问题诊断"表）
4. **口述确认**（分章节对话式讲内容，用户答 `1`=过 / `2`=改 / `0`=全对直接生成；口述前先定**认知引导叙事弧线**）
5. **设计感与模板匹配**（用户指定 > **网搜候选给用户看图选（默认）** > gorden 内置兜底；附 2-3 个候选 + 预览图；生成前先定**视觉定调 ≤3色/≤2字体/固定版式位 + 每页设计指令表**）
6. **生成**（gorden 底座或 python-pptx，只改文字不动排版，selected_slides 尽量选不同版式页）
7. **配图**（真实图优先，配图放独立页面附内容页后；**封面/章节页/视觉页可用生图模型整页生成主视觉**，文字密集页禁用）
8. **清理统一**（残留扫描必选、统一"章名/节名"标题必选、改色可选）
9. **渲染自检交付**（逐页渲染核对版式雷同/生图乱码/**设计纪律五铁律**，只交 PPTX）

## 安装

把本仓库 clone 到你的 AI 技能目录（如 `.user_skills/` 或 `.claude/skills/`），或直接复制整个 `general-ppt` 文件夹：

```bash
git clone https://github.com/liuning60/general-ppt.git
# 目录名即 general-ppt，直接放入技能目录即可
```

依赖（各平台通用）：

- Python 3 + `python-pptx`
- LibreOffice + `pdftoppm`（用于渲染自检，可选）
- 内置模板来自 [gorden-ppt-skill](https://github.com/GordenSun/GordenPPTSkill)（clone 到技能目录后自动可用，仅兜底）

## 脚本清单（scripts/）

| 脚本 | 作用 | 必选/可选 |
|---|---|---|
| `recolor_theme.py` | 全量改色（theme + slides + charts + layouts 全遍历） | 可选（点名才用） |
| `scan_leftover.py` | 模板残留词全量扫描（交付前必跑） | 必选 |
| `clean_leftover.py` | 按替换表清理残留文字 | 必选（扫出命中时） |
| `add_photo_pages.py` | 内容页后插入配图页（深色标题条 + 2 图 + 图注） | 按需 |
| `unify_titles.py` | 删旧标题 + 统一"章名/节名"标题框 | 必选 |

## 跨平台适配（重点）

工程骨架（模板生成、清理、配图、渲染）全部是**本地 Python 脚本，天然跨平台**；「网络真实图搜索」「AI 生图兜底」和「生图主视觉」三个能力依赖平台，按下表映射到各平台自身能力：

| 能力 | 豆包（默认） | OpenAI Codex | Gemini CLI | Claude Code |
|---|---|---|---|---|
| **网络真实图搜索** | `image_search`（拆实体关键词、中英双语） | 平台代码/网页搜索能力 | 平台搜索能力 | 平台搜索能力 |
| **AI 生图兜底模型** | `image_gen`（seedream 4.5 / 5.0 Pro） | 内置 imagegen skill（GPT Image：gpt-image-1 / 1.5） | Nano Banana（`gemini-3.1-flash-image` / `gemini-3-pro-image`） | **无原生生图能力** → 经 MCP/CLI 接入外部生图服务，或降级用 SVG/HTML 绘制图表 |
| **生图主视觉**（封面/章节页/视觉页整页生成） | `image_gen`（seedream 4.5 / 5.0 Pro） | 内置 imagegen（GPT Image） | Nano Banana | **无** → 跳过此保障，用真实图+模板兜底，绝不假装 |
| 模板生成 | `build_pptx.py` | 同左 | 同左 | 同左 |
| 渲染自检 | `render_slides.py` | 同左 | 同左 | 同左 |

> **生图规则**（各平台一致）：AI 生图只用于「网上找不到真实图 + 确需画面」的最后手段，以及「封面/章节页/视觉页」的主视觉整页生成；界面/软件图必须真实截图（AI 生成必乱码）；**文字密集页禁用生图主视觉**；画面尽量无文字；标注"AI 示意图"；生成后逐字核对。
>
> **Claude Code 特别说明**：Anthropic 官方确认 Claude 不具备图像生成能力（2026 年 4 月重申，Claude 5 仍无）。确需 AI 生图时，用 MCP 接入生图服务（如 Clize、DreamPixel Forge 等），或按知识类型降级为 SVG/HTML 图表——绝不强行假装有生图能力。

## 常见误区

- 不要拿到需求就生成 —— 4 问没答全、密度没过、口述没确认，都不许动手
- 不要编造数字 —— 用户没给的数据标"待补充/估算"
- 不要默认用 gorden 内置旧模板 —— 默认先网搜新潮模板给用户看图选，内置只兜底
- 不要整份 deck 同一版式套到底 —— 版式多样性是硬规则
- 不要在生图主视觉里塞大段文字 —— 只用于封面/章节页/视觉页，生成后逐字核对
- 不要用 AI 生图冒充真实图 —— 界面图必须真实截图
- 不要只交 PPTX 不渲染自检
- 不要在没合适模板时硬套或凭空画 —— 先网搜给用户确认
- 不要信息倾倒 —— 每页只讲一件事，其余留白；详细内容放演讲备注（v2.1）
- 不要表格挤满 / 截图粘贴数据 —— 数据用大字号数字 + 一句结论（v2.1）
- 不要超过 3 色、2 字体 —— 克制是高级感的第一性原理（v2.1）
